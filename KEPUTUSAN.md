Default yang tidak diputuskan lewat pertanyaan (berlaku sampai diveto):
- Nama repo dan paket: `ingat`.
- Satu vault Obsidian untuk semua proyek; `lingkup` ada di frontmatter tiap catatan.
- Transport MCP v0: stdio (lokal, Claude Code). HTTP menyusul untuk VPS.
- Versi Node dikunci: 22.x ≥ 22.13 (`node:sqlite` tanpa flag) — lihat `.nvmrc`.
- Frontmatter `ingat` = subset YAML: satu kunci per baris; nilai skalar atau JSON *flow style*
  (`bukti: ["ep-1"]`, `berlaku_untuk: {"node": "22"}`). Obsidian merender keduanya. Alasannya: parser tanpa dependensi.
- Yang di-embed per episode di v0: `ringkas` + 1.500 karakter pertama `isi` (jendela e5 = 512 token).
  Pemotongan bertahap (multi-vektor per episode) = fase 2.
