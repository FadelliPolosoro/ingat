# Aturan lisensi

- Repo: Apache-2.0. Setiap berkas sumber baru diawali header ringkas:
  `// SPDX-License-Identifier: Apache-2.0` (cukup satu baris; teks lisensi ada di LICENSE).
- Dependensi runtime: **tidak ada** di v0. Menambahkannya = keputusan pemilik.
- Dependensi dev: hanya MIT, Apache-2.0, BSD-2/3, ISC, 0BSD, CC0, PostgreSQL.
  Dilarang: SSPL, BSL, Elastic, Commons Clause, dan semua "source-available".
- Jangan salin kode dari proyek lain. Pola boleh dipinjam; catat di Lampiran C spek.
  Kalau suatu saat menyalin fungsi berlisensi MIT, tambahkan notice-nya ke `THIRD-PARTY-NOTICES`.
- Bobot model: hanya yang lisensinya permisif dan tercatat di `model/README.md`.
